# Instruções para o Claude

o usuário é leigo e só colou o comando de clone deste repositório. Faça tudo sozinho, sem pedir que ele rode nada:
1. Depois do clone, copie as 3 pastas de `skills/` para `~/.claude/skills/` (no Windows: `%USERPROFILE%\.claude\skills`), criando a pasta se não existir. Se já existir skill com o mesmo nome, não sobrescreva sem avisar.
2. Confira que cada skill ficou com o `SKILL.md` direto dentro da sua pasta e mostre a lista do que foi instalado.
3. Avise, em português simples, que ele precisa fechar e abrir o Claude Code de novo para as skills aparecerem.
4. Pergunte que nome ele quer no lugar de `coloqueseunomeaqui` (nome dele, do escritório ou do método) e faça a troca nas 3 cópias instaladas, seguindo a seção "Antes do primeiro uso" de cada skill.
